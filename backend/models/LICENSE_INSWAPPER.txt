1. MODEL IDENTIFICATION & REPOSITORIES
--------------------------------------------------------------------------------
Model 1: Inswapper 128 (inswapper_128.onnx)
  - Purpose: Neural face-swapping generator (128x128 canonical resolution)
  - Upstream Project: InsightFace (https://github.com/deepinsight/insightface)
  - Checkpoint Host: Hugging Face (ModelsLab/inswapper, Gourieff/ReActor)
  - Input Tensors:
      * 'target': [1, 3, 128, 128] float32 RGB normalized to [0, 1]
      * 'source': [1, 512] float32 normalized identity latent vector
  - Output Tensor:
      * 'output': [1, 3, 128, 128] float32 RGB in range [0, 1]

Model 2: ArcFace ResNet-50 (w600k_r50.onnx)
  - Purpose: 512-dimensional facial identity embedding extraction
  - Upstream Project: InsightFace Buffalo_L model zoo
  - Checkpoint Host: Hugging Face (maze/faceX, Aitrepreneur/insightface)
  - Input Tensor:
      * 'data': [1, 3, 112, 112] float32 BGR normalized with mean=127.5, std=127.5
  - Output Tensor:
      * 512-dimensional normalized feature vector
